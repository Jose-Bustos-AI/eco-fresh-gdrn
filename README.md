# Eco Fresh GDRN · web de demostración

Web de demostración para una empresa de limpieza en Málaga: calculadora de presupuesto, comparador de antes y después, comprobador de zona y suelo que se friega pasando la mopa.

**Verla publicada:** https://eco-fresh-gdrn.vercel.app/

## Cómo está hecha
- HTML, CSS y JavaScript propios, sin framework ni librerías externas
- Efecto de fregado en canvas
- Imágenes y vídeo optimizados (de 8,1 MB a 1,5 MB por visita)
- Alojada en Vercel

## Verla en local
```
python -m http.server 8000
```
y abre http://localhost:8000/

## Sobre esta web
Diseño y desarrollo de [Dania360](https://dania360.com). Es una demo: los textos, las fotos y la marca del negocio pertenecen a sus dueños, y la web no se indexa en buscadores (`noindex`). El código se publica para enseñar cómo está hecha; no tiene licencia de uso.

Más webs en el portafolio: https://dania360-portafolio.vercel.app
